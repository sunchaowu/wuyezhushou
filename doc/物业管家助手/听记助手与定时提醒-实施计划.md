# 听记助手与定时提醒 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 楼栋网格内离线听记（收费/事件/特征标签提案）、房号+业务词立刻切沟通页、本机定时提醒；标签支持 `description` 语义匹配。

**Architecture:** ASR → 规则粗筛 →（M3.5）端侧 Tiny NLU 复核 → 提案/导航；写入一律确认卡片；复用现有 `UpdateRoomUseCase` / `Routes.roomCommunication`。

**Tech Stack:** Kotlin + Room + Hilt + Compose；sherpa-onnx ASR；ONNX Runtime Mobile（M3.5）；JUnit4；`scripts/build-android.sh test|debug`。

## Global Constraints

- 完全离线：运行期不联网 ASR/LLM/推送
- 进入网格开听、离开停听；仅点名房号不跳；唯一匹配立刻跳
- 写入前确认；金额不静默换算；无 description 不硬编码同义
- DB version 5 → 6（description + room_events + reminders）
- 包根：`com.guanjiazhushou.assistant`
- 验证：`./scripts/build-android.sh test`（需要时 `debug`）；有错误提示原因，不降级绕过
- aliases 为 P1，不阻塞 M1
